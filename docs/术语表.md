# 术语表（面向人的用词）

本文件规定**用户能看到的中文用词**。它不改变任何内部字段——那是契约。

## 三层，别混

| 层 | 例子 | 能不能改 |
|---|---|---|
| 内部枚举 / 字段名 | `phase: 'off' \| 'lead' \| 'peak'`、`gateMode: 'hard'`、`enabled` | **不改**。它们在 `/api/peak-brief.state`、`peak-brief/phase` 事件、`transitions.ndjson` 里，`dsh-bridge` 在订阅；也是配置文件的落盘值。 |
| 面向人的文字 | 横幅、`/peak-status`、拦截提示、设置页说明 | **只用中文词，零枚举**。统一由 `lib/words.js` 生成。 |
| 配置取值 | `off` / `peak` / `hard` / `popup` | 保留英文（配置契约），但设置页说明里必须给出中文对照。 |

## 词表

| 内部（不改） | 面向人 | 备注 |
|---|---|---|
| `off` | **空闲时段** | DeepSeek 官方计费页原词。口语里的“谷时/谷段”可以，但界面统一用官方词。 |
| `lead` | **高峰前** | 不是计费时段，是插件的动作窗口：生成交接简报、暂停自动续跑。 |
| `peak` | **高峰时段** | 官方原词。 |
| `blocking: true` | **正在拦截** / 最高频的说法是「本段 12:00 结束」 | 用户只关心“还要等多久”。 |
| `blocking: false`（在空闲时段） | **不会拦截** | |
| `gateMode: 'hard'` | **拦截：开** | |
| `gateMode: 'off'` | **拦截：关（只提醒，不拦）** | |
| `enabled: false` | **拦截：关（不会拦任何请求）** | |
| `leadMinutes` | **提前 N 分钟准备** | 不再叫“提前量”。 |
| `resumeBlocked` | **高峰过后自动继续** | 被拦的请求在空闲时段原地重发。 |
| 挂载（mounted） | **已加载 / 启动** | “挂载”是文件系统行话。 |
| 相位（phase） | **时段** | 状态机视角的词，不进界面。 |
| 门控（gate） | **拦截** | |
| 硬拦 | **拦截** | |

禁止出现在界面里的词：`相位`、`门控`、`硬拦`、`挂载`、`提前量`，以及裸枚举
`off / lead / peak / hard / enabled / popup / message`（命令名与 URL 里的 `peak-allow`
属于专名，不算）。

## 依据：DeepSeek 官方计价（2026-11-08 核对）

> 空闲时段价格为高峰时段价格的一半。**北京时间周一至周五（不含中国法定节假日）
> 9:00 - 12:00、14:00 - 18:00 为高峰时段；其余时段，包括周末及中国法定节假日全天
> 均为空闲时段。**

来源：<https://api-docs.deepseek.com/zh-cn/quick_start/pricing>
（英文页同一句话，时间写作 UTC：`01:00-04:00` 与 `06:00-10:00 UTC`。）

本插件的默认 `peakWindows`（09:00–12:00 / 14:00–18:00，工作日，法定节假日全天不算）
与上述口径**一致**；`data/*.json` 里的法定节假日表就是“不含中国法定节假日”那半句。

⚠️ 官方明示“保留调价权利”。这份表只保证 **2026-11-08 核对时**的用词与口径；
价格倍数（半价）不要写进界面文案，写死了就会变成下一个“快照冒充现状”。

## 落地位置

| 位置 | 说明 |
|---|---|
| `lib/words.js` | 唯一词表 + 句模板（`nowLine` / `gateLine` / `nextLine` / `blockMessageText`） |
| `lib/index.js` `statusLines()` | 挂载横幅与 `/peak-status` 共用这三行 |
| `lib/gate.js` `blockMessage()` | 拦截提示走 `blockMessageText()` |
| `lib/settings.js` | 设置页每条说明以“人话标题：”开头，枚举取值在括号里给中文对照 |
| `test/host.integration.test.mjs` | 「用词：所有面向人的输出都用时段说话」——四处文案一起钉住，出现枚举或行话即红 |

## 如果以后真要改内部枚举

`off → idle` 这类改动会同时打破：`/api/peak-brief.state` 的消费方、`peak-brief/phase`
事件订阅（dsh-bridge）、`transitions.ndjson`、已落盘的 profile 配置、README 里的 curl 示例。
收益只是“名字更顺眼”，代价是一次跨仓迁移。**不做**；翻译只发生在 `lib/words.js` 这一层。
